## 🚀 Setup Instructions

### Step 1: Run SQL in Supabase
1. Go to your Supabase project dashboard
2. Navigate to **SQL Editor**
3. Open the file: `supabase-tables.sql`
4. Copy and paste the entire SQL script
5. Click **Run** to execute
6. You should see: "Database setup complete! 6 tables created..."

### Step 2: Configure Environment Variables
Make sure your `.env` file or Vercel environment variables include:
```
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_KEY=your_supabase_anon_key
```

### Step 3: Access Admin Panel
1. Navigate to: `http://localhost:8000/pages/admin.html`
2. Enter default PIN: `admin123`
3. Click Login

### Step 4: Change Default PIN
1. After logging in, scroll down to "MSG91 Integration Settings"
2. Enter a new PIN in the "New admin PIN" field
3. Click "Update Admin PIN"
4. Remember this PIN for future logins!

## 📊 How to Use Admin Features

### Managing Job Applications
1. Go to "Job Applications" section in admin panel
2. Search applicants by name, phone, or position
3. Click "View" to see full application details
4. Use status dropdown to update application status:
   - **Pending** - New application (default)
   - **Reviewed** - Application has been reviewed
   - **Shortlisted** - Candidate shortlisted for interview
   - **Rejected** - Application rejected
   - **Hired** - Candidate hired
5. Click "Export Job Applications CSV" to download all data

### Viewing Payments
1. Go to "Payment Transactions" section
2. Filter by date (Today/This Week/This Month/All Time)
3. Search by name, phone, or payment ID
4. All successful Razorpay payments are automatically tracked
5. Click "Export Payments CSV" to download transaction history

### Adding Employees
1. Go to "Employee Management" section
2. Enter employee name, email, and password
3. Click "Add Employee"
4. Employee ID is auto-generated (UUID format)
5. Each employee can log in at `/pages/employee-login.html`
6. Track performance: see how many members each employee added

### Employee Dashboard Features
When employees log in, they can:
- Add new members to the system
- Convert members to Premium
- View their performance stats
- Track their added members
- Each action is logged with their employee ID

## 🔧 Technical Details

### Database Schema
```
employees
├── id (UUID, auto-generated)
├── name
├── email (unique)
├── password
├── role
├── status
└── created_at

job_applications
├── id (UUID, auto-generated)
├── name
├── phone
├── email
├── age
├── qualification
├── experience
├── position
├── district
├── address
├── skills
├── message
├── status (pending/reviewed/shortlisted/rejected/hired)
└── created_at

payments
├── id (UUID, auto-generated)
├── member_id (FK to members)
├── razorpay_payment_id (unique)
├── razorpay_order_id
├── amount
├── name
├── phone
├── email
├── method
├── status
└── created_at
```

- **Razorpay**: Payment gateway for premium memberships
- **Forms**: Client-side validation + server-side storage
